## 浏览器检查范围

- 新用户首页进入第一课，答错有正确答案与解析，两题提交后可完成，重复完成不累加；重做会重新要求提交。
- 16 道题逐一作答并查看正确反馈，8 课全部完成后首页显示复习入口。
- 刷新恢复答案、课程与完成状态；关闭 Chromium 后以同一磁盘配置重新启动，答案仍可恢复。
- 重置窗口取消会保留数据，确认会清除记录。
- 损坏记录、禁用 localStorage、写入失败都显示提示，阅读和练习继续工作。
- 简繁卦名、数字与首尾空格、上下卦交集过滤、筛选 URL 刷新、空结果和清空有效。
- 64 个详情页均可到达，页面内部链接目标有效；每页恰有 6 条爻辞；乾坤附加经文独立。
- 点击或键盘选择爻位，图与文字对应；课程跳往相关卦后可以返回课程。
- 所有课程、64 卦、首页、索引、记录与来源页加载时没有 pageerror 或 console.error。
- 已加载应用切为离线后仍可跨 hash 页面阅读和答题。未增加 Service Worker，不宣称浏览器首次离线访问或离线硬刷新可用。
- 360、768、1440 像素宽度下检查所有页面类型，无文档横向溢出；截图保存在 `docs/screenshots/`。
- 关键练习操作验证 Tab、Space 和 Enter。不是完整 WCAG 审计，也未实测屏幕阅读器或所有移动浏览器。
